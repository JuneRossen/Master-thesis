# Master-thesis
This repository stores the Jupyter notebooks used in June Rossen's Master thesis titled "Minimizing socio-environmental impacts of onshore wind power development in Norway", a project conducted at EPFL and NINA.

For an explanation of the general workflow of the notebooks, please refer to the Methods section of the thesis. 

Necessary files to run the notebooks can be found at:
Rossen, June (2026), “MasterThesis_JuneRossen”, Mendeley Data, V1, doi: 10.17632/cp4wcv352s.1
